========================================
  Auto Kill Beam — คู่มือการใช้งาน
========================================

ฟีเจอร์นี้ป้องกันการลืมกด Kill beam หลัง run จบ

----------------------------------------
CHECKBOX "Auto kill beam (10s)"
----------------------------------------
อยู่ใต้ปุ่ม Kill beam

  [ ] ไม่ติ๊ก  → ปุ่ม Kill beam กะพริบสีส้ม/แดงเตือนเท่านั้น
                  ไม่มีการ kill อัตโนมัติ — ต้องกดเอง

  [✓] ติ๊กไว้  → ปุ่มกะพริบ + นับถอยหลัง 10 วินาที
                  ครบ 10 วิ = kill beam อัตโนมัติ

----------------------------------------
FLOW หลัง RUN จบ
----------------------------------------

  1. Run complete → toast แจ้งสถานะ
  2. ปุ่ม Kill beam เปิดใช้งานและเริ่มกะพริบ
  3a. [ไม่ติ๊ก] กะพริบจนกว่าจะกด Kill beam เอง
  3b. [ติ๊กไว้]  ปุ่มแสดง "Kill beam (9s)" → "Kill beam (8s)" → ...
                  ครบ 10 วิ = kill อัตโนมัติ

----------------------------------------
การยกเลิก countdown (กรณีติ๊ก auto kill)
----------------------------------------
กด Kill beam ก่อนครบ 10 วิ → countdown หยุดทันที
ปุ่มหยุดกะพริบและดำเนินการ kill beam ตามปกติ

----------------------------------------
หมายเหตุ
----------------------------------------
- ค่า default ของ checkbox คือ ไม่ติ๊ก (ปลอดภัย)
- ต้องการ enable beam ก่อน Kill beam จึงจะทำงานได้
- หาก FPGA ไม่ได้ต่ออยู่ countdown จะหยุดและแจ้ง error
